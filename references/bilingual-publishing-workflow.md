# 中英文、HTML 配图与发布验证

适用于用户要求完整博客交付、整理进博客或验证后发布。普通文案讨论不运行整套发布流程；仅请求改稿时不展开部署。具体站点、仓库、分支、平台、入口与凭据从当前项目读取，不从历史案例猜测。

## 1. 明确范围和项目事实

- 读取适用的仓库指引、Git 根目录、远端默认分支和工作树状态。保存已有改动，不能覆盖；从同步后的默认分支开始本次内容分支，或沿用本次已建立的分支。
- 识别内容目录与 schema、现有双语文件/slug规则、静态资源目录、图片放大功能、文章模板及语言切换机制。
- 读取实际构建命令、锁文件、CI触发条件、预览/生产目标、默认分支自动发布开关，以及目标域名的当前源码与部署版本。
- 明确作者认可的是哪版正文。内容变更与站点/API变更分开：本轮通常只含文章、图源和图片，不顺带改框架、鉴权、数据库、域名或后台。
- 形成足够简短的发布记录：范围、用户授权、基线、验证方式、发布顺序、回滚点。已有授权覆盖同一目标和范围时无需重问；不明确的生产目标或扩大范围才澄清。

## 2. 中英文成稿与站点适配

- 中文以作者认可版本为基线，保留真实动机、名称、判断过程和手动改动；落盘不应再变回模板化导读、方法论或总结清单。
- 英文按自然英文重写，保留相同事实、引用、数字、失败实验和未完成事项，不增造经历；不要逐句翻译中文句法。
- 按项目约定设置 title、date、excerpt、category、lang 等元数据；日期使用用户时区。摘要只承诺正文实际提供的内容。
- 同一文章语言路由对应正确，不默认所有站点都采用 `-en.md`；项目沿用该约定时保持一致。标题由模板输出时正文从 H2 开始，章节编号使用阿拉伯数字。
- 对照两语核查产品名称、单位、免费/付费边界、估算与实付、性能口径及样本限制。章节只在需要时对应，不要求所有文章恰好若干节。
- 源码中的本地绝对路径替换为正式资源路径。外部引用直接支持相邻主张，易变价格和额度记录核对日期。
- 不默认新增装饰封面或付费生成任务。解释图已在正文时，确认 ogImage 是否同时会渲染文章头图，避免无意重复长图；可沿用站点既有分享图。

## 3. HTML/CSS 解释图 → PNG

- 先确定读图任务，再用 HTML/CSS 排版；比较时明确单位、统计窗口及套餐边界。中英文分别适配文字长度，不能只换正文却保留另一语言的图中文字。
- 使用本地字体回退与资源，避免网络字体、图片加载失败影响截图。按实际正文宽度和手机阅读安排字号，长英文适当换行；需要时提供纵向版。
- 浏览器真实渲染，等待字体/图片就绪，测量内容边界和文字溢出，再按实际高度截图。高分辨率按阅读需要选择，不机械固定尺寸或倍数。
- 导出后实际查看 PNG：检查最后一行、卡片文字、箭头、裁切、留白及缩小阅读。DOM无溢出不能替代查看图片；布局截图不能替代交互测试。
- 区分说明图与真实产品截图，不用绘制图冒充报错证据。图片有语义化文件名、正确 alt 和公开资源地址。
- 图源放入仓库可追踪的位置，例如项目已有图源目录；PNG放静态资源目录。先检查 gitignore，不把图源只留在被忽略的笔记或临时目录里，不为此粗暴取消全目录忽略。
- 截图失败先读取当前页面状态，区分导航已提交、截图通道故障和真实排版错误；不要每次新建浏览器任务或盲目重试。按可用浏览器工具规范恢复，必要时用隔离的本地无头浏览器渲染自有HTML，不读取用户会话或凭据；仍无法产图就保留源文件并说明，不声称已检查图片，也不擅自升级浏览器。

## 4. 本地验证

先构建，再检查本轮新增文章及相邻入口。沿用既有发布必需检查；不为静态内容改动额外全量测试无关系统。

- schema、日期、摘要、正文标题层级和阿拉伯数字编号通过；专名一致，无旧拼写、占位符、私有路径、凭据或原始日志。
- 两语关键事实和表格数字一致；实际构建输出包含两语正文和对应图片。
- 从 `.prose` 或站点实际正文容器核对标题与内容，排除评论区、推荐区和页脚，不能按整页 H2 数量判断文章章节。
- 桌面与手机宽度下检查页面水平溢出、正文图片自然尺寸和显示尺寸、表格自身滚动与页面溢出的区别。若站点有图片放大，实际点击并验证关闭或 Escape。
- 检查两语标题、URL、语言标记和配图是否确实切换。站点按浏览器语言或偏好自动跳转时，通过真实语言切换控件验证另一语言，等待 URL 和新正文都满足条件，不在旧 DOM 上立即读取。
- 核对 canonical/hreflang、语言互链、列表发现、RSS、sitemap和其他站点已有索引（例如llms.txt）。未启用的功能记为不适用，不为验证一篇文章新增功能。
- 本地无脚本截图可以验证静态布局，但不能证明语言切换、图片放大或动态接口可用。分别记录视觉证据、DOM测量和真实交互。

## 5. 保存候选与隔离预览

- 提交文章、图片及可编辑图源；确认改动范围、工作树干净。创建或更新内容 Code PR，记录实际本地检查和回滚方案。
- 部署输入必须来自已提交源码与对应产物。若构建后改了文件或切换了提交，重建，不上传陈旧产物。
- 使用现有无生产域名的隔离预览，确认 noindex；按项目预览政策关闭生产分析与写作副作用，不向预览注入生产凭据来让探针变绿。
- 预览验证新增文章、图片公开字节、语言/SEO/发现入口与真实浏览器阅读交互。图片可以用 SHA-256 或逐字节比较，与本次提交资源对应。
- 只对相关 API 做必要只读检查。先确认现有基线：预览可能明确关闭写作，缺配置返回503不能一律当鉴权401失败；也不能把任意503都视作通过。由源码、配置存在性或既有记录证明预期行为。生产鉴权继续按其真实契约核验。
- 不用真实写文章、发评论、删内容、发邮件或调用付费模型试探发布；需要这些验证时另有明确范围、隔离数据和回收策略。
- 记录预览提交、CI任务、实际产物摘要、平台版本、URL和结果。修复探针自身错误时保留说明，不伪造失败已通过。

## 6. 默认分支生产发布

- 预览通过、内容审查和既有发布门禁满足后，将内容 Code PR 合入默认分支。用户已明确要求验证后发布的，继续执行已授权步骤。
- 生产使用精确默认分支提交；使用实际读取的完整SHA，不猜测或补全短哈希。默认分支自动发布已开启时，确认相应任务成功，避免同时再手工部署同一内容。
- 若项目无自动发布，按既有发布命令发布该已合并候选，不临时更换平台。构建输入、目标和凭据来源必须明确。
- 获取本次 CI 的真实产物摘要。含动态数据的构建可能在本地与CI不同，不要求两次独立构建字节完全一致；应证明部署使用的是该次已确认CI产物。
- 未完成发布验证时报告“已构建/已预览/发布中”，不提前宣布上线成功。CI失败时先检查错误，不反复触发相同构建或放宽门禁。

## 7. 正式入口验证与收尾

- 在正式固定域名核对两语文章响应与实际内容；图片状态、类型及公开字节匹配提交资源；语言互链、canonical/hreflang、列表、RSS和sitemap等仍正确。
- 生产页没有误留预览noindex；分析配置按项目基线保留。不要把正文讨论的“noindex”等词误判成页面配置。
- 正式页面复查手机阅读、真实语言切换、图片加载和放大。记录实际URL与标题，避免语言分流掩盖错误。
- 读取平台实际部署/版本与域名绑定，结合项目提供的源码指纹或可追踪产物，确认线上来源对应生产默认分支。仅看到Server为Cloudflare不能证明来源或版本。
- 若有写作/评论API且本轮随同一应用发布，核对健康与无效凭据拒绝等无副作用契约；不读取或输出凭据。无关后端、数据库不变。
- 生产验证失败时停止核销并按预先记录回滚点处理，保留真实失败。不能为让文章探针通过而临时关闭全站安全策略、改密码或扩大部署范围。
- 将CI、产物摘要、源码、平台版本、最终URL、验证结果及残留项回填现有PR/发布记录；遵守项目Code PR/Release PR分工。记录被gitignore忽略时，沿用项目约定在PR正文或CI产物归档关键证据，不误称这些本地文件已提交。
- 同步默认分支，核对本地/远端HEAD和干净状态；保留原有用户改动。停止本轮创建的本地预览服务，按浏览器规范结束任务，不清理无关资源。
- 最终交付中英文正式链接、简短验证结论和PR/发布记录。图源及PNG随内容版本保留；不重复粘贴整篇正文或冗长部署日志。

## 8. 本轮可维护的记录

项目现有规范允许时，维护一份精简记录即可，避免为每篇创建整套研发文档：

| 记录项 | 需要证明的内容 |
|---|---|
| 正文与资源 | 两语文件、slug、图片及图源位置、用户认可的版本 |
| 事实核对 | 数据来源、价格核对日期、估算和实测边界 |
| 本地与预览 | 构建结果、实际浏览器语言/交互、图像检查、适用/未执行项目 |
| 生产与回滚 | 默认分支源码、CI与产物摘要、平台版本、固定URL、回滚基线 |
| 最终状态 | 真实失败和修复、残留事项、默认分支归位 |

这里只描述可复用流程；实际仓库地址、账号、域名、版本、测试数量及凭据保存在项目事实源，不写入本 skill。
