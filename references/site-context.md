# 目标博客适配检查

真实站点事实从本轮仓库、项目文档、schema、现有文章和部署配置读取；通用skill不固定博客地址、云账号、工作流名称或凭据来源。

- 内容：确认是否Astro，读取内容集合schema、日期/语言字段、中文/英文文件名与slug规则。常见目录 `src/content/blog/` 和 `-en.md` 只是线索，不是所有站点的要求。
- 资源：确认公开图片目录、可编辑HTML图源的跟踪位置、图片放大行为及ogImage是否同时显示为封面。gitignore中的本地文档不要误当版本化图源。
- 语言：确认独立路由、canonical/hreflang、浏览器语言和用户偏好的分流行为。实际切换后核对新正文。
- 发布：确认默认分支、构建命令、现有CI、preview/production隔离、自动发布开关和源码指纹。沿用Vercel、Cloudflare或项目已有平台，不根据旧案例迁移。
- 证据：从本轮项目的提交、测试和发布记录取材，不读取或公开环境密钥、用户数据、私有日志。公开文章只保留可公开的事实与图片。
- 原Claude版本与Codex版本独立维护；修改本skill不默认回写其他目录。
